# Dotfiles

Personal development environment configuration for Linux.

## Install

Install the complete environment:

```bash
./install.sh
```

## Available configurations

### Yazi

Terminal file manager configured for development and SSH workflows.

Install:

```bash
./yazi/install.sh
```

### Zsh

Shell configuration with Oh My Zsh and development tooling.

Install:

```bash
./zsh/install.sh
```

### Tmux

Terminal multiplexer configuration for development and remote SSH workflows.

Install:

```bash
./tmux/install.sh
```

### Neovim

Modern Neovim configuration with LSP, completion, Tree-sitter, Telescope and Yazi integration.

Install:

```bash
./nvim/install.sh
